# Code of Conduct

This project is for people who build and use Agent Skills. Everyone who takes part in an
issue, a pull request, a discussion, or any other project space agrees to follow these rules.

## What we expect

- Be respectful. Disagree with ideas, not with people.
- Give reviews that are specific and kind.
- Assume good intent. Ask when something is unclear.
- Protect privacy. Never post another person's personal data.

## What is not acceptable

- Harassment, threats, insults, or discrimination.
- Sexual language or images.
- Sharing private information about others.
- Spam, or repeated off-topic posts.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, discussions, and pull requests that
break these rules. They may block people who keep breaking them. Maintainers decide in good
faith and explain the decision when they can.

## Report a problem

Use the private report form: <https://github.com/revenantworks/claude-skills/security/advisories/new>.
Start the title with "Conduct report". Only maintainers can read it.
