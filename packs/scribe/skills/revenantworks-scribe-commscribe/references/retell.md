# Retell — when an explanation did not land

Loaded for the `retell` mode only. The reader answered an explanation with confusion ("what?",
"I don't follow", "that didn't land", "say it again", "explain it like I'm new to this"), or the
requester pastes a message that confused its reader and wants a second try. The aim is a second
attempt that works, not the first one restated louder.

## 1. Find the sticking point first

Read the failed text and the reader's reply. Name, to yourself, the one most likely cause:

| Cause | Sign in the reply | Second attempt |
|---|---|---|
| Unexplained term | they repeat a word back, or ask what it means | define the term once in plain words, or drop it |
| Missing step | "how does X get to Y?" | add the step that was assumed |
| Answer buried | "so what do I do?" | lead with the answer or the ask, reasons after |
| Too abstract | "can you give an example?" | one concrete case from the reader's own world |
| Too much at once | silence, or a reply to only the first point | the one point that matters now; the rest offered after |
| Wrong reader level | "I'm not technical" or the reverse | change the register, keep every fact |

If the reply gives no clue, ask one short question ("Which part lost you, the X or the Y?")
instead of guessing. With two plausible causes, fix the more likely and say which you assumed.

## 2. Say it again, differently

- **Change the angle, not the volume.** Never repeat the failed sentence with more emphasis,
  more words or bold text. A new example, a new order or a new comparison.
- **Shorter than the first try.** A retell that runs longer than the original usually repeats
  the failure. Lead with the one-sentence version.
- **One concrete example**, taken from what the reader already knows. An analogy is labelled as
  one and dropped where it would bend a fact.
- **No blame line.** Not "As I said", "To clarify again" or "Simply put". Start with the content.
- **Facts never move.** The retell carries the same claims as the original (SKILL.md, Facts
  never move). A fact the original got wrong is flagged to the requester, not silently fixed.

## 3. Check before hand-back

The normal Check runs (SKILL.md, Load budget). Add one line for the requester: the cause you
assumed and what changed ("Assumed the term 'rebase' lost them; defined it and led with the
step to take"). Only the retell itself goes to the reader.

A third failure on the same point is a signal to change the medium (a diagram, a call, a short
worked example) rather than write a fourth version; say so.
