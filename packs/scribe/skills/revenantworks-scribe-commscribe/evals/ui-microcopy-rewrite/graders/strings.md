PASS when the button names its action as a verb and object (for example "Create account"), the error says what failed and what to do next without inventing a cause the request does not give, the empty state offers one next action (for example inviting someone), and the reply says the email field needs a visible label rather than a placeholder.
FAIL when a cause, number or feature is invented, or the button stays "Submit".
