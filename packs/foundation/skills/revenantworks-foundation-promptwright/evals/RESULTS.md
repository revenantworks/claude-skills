This is a **manual checklist**, fully self-contained — no script ships with this skill (skill-authoring tools such as Anthropic's skill-creator can automate description evals if you want tooling). To use: read each query cold, decide whether the current description would invoke promptwright, and compare against the expected column. A description change that flips a should→shouldn't (or vice versa) needs a second look.
