# Accessibility

## Our commitment

We want everyone to be able to read, install, and use these skills. That includes people who
use screen readers, a keyboard only, or high zoom.

## Supported environments

- Documentation: Markdown, read on GitHub or in any text editor.
- Skills: Claude Code and other tools that support Agent Skills.
- Scripts: a command line with Python 3.9 or later.
- Mods that change Claude's own interface, such as `dash`: Claude Code.

## What we do

- We write documentation in plain language, with short sentences.
- We keep headings in order and give links descriptive text.
- We fix reported barriers as quickly as we can.

## Known limits

- We have not had a formal accessibility audit.
- We have not tested mod interfaces with screen readers.
- Some documents use tables and code blocks that a screen reader may read slowly.

## Report a barrier

Open an issue and choose "Accessibility barrier":
<https://github.com/revenantworks/claude-skills/issues/new/choose>.
Tell us where you hit the barrier and what you use to read or run the project. If you would
rather not use a public issue, use the private form in `SECURITY.md`.
