# Support

Read the `README.md` first. Each skill folder also has its own README.

| You need | Go to |
|---|---|
| An answer or an idea | [Discussions](https://github.com/revenantworks/claude-skills/discussions) |
| To report a bug or ask for a feature | [New issue](https://github.com/revenantworks/claude-skills/issues/new/choose) |
| To report an accessibility barrier | [New issue](https://github.com/revenantworks/claude-skills/issues/new/choose), "Accessibility barrier" |
| To report a security problem | [Private form](https://github.com/revenantworks/claude-skills/security/advisories/new) |

Do not paste secrets, real names, personal paths, or email addresses into any public space.
