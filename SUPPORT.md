# Support

Read the `README.md` first. Each skill folder also has its own README.

| You need | Go to |
|---|---|
| An answer or an idea | [Discussions](https://github.com/revenantworks/claude-skills/discussions) |
| To report a bug or ask for a feature | [New issue](https://github.com/revenantworks/claude-skills/issues/new/choose) |
| To report an accessibility barrier | [New issue](https://github.com/revenantworks/claude-skills/issues/new/choose), "Accessibility barrier" |
| To report a security problem | [Private form](https://github.com/revenantworks/claude-skills/security/advisories/new) |

Do not paste secrets, real names, personal paths, or email addresses into any public space.

## Support period

**Support period.** Every pack and featured plugin in this repository, major version 1, gets
security fixes until 2027-11-23. Only the latest release in that line gets fixes. After that date
it gets no fixes of any kind and is end-of-life. Feature updates are not promised. End-of-life
dates for every version are listed here.

| Line | Covers | Security fixes until | Status |
|---|---|---|---|
| 1.x | every pack (`foundation`, `scribe`, `warden`, `localops`, `gamedev`, `hearth`) and every featured plugin in `featured/` | 2027-11-23 | supported |

A new major version gets its own row and its own date, set when it ships. The date may be renewed
for a line that is still maintained; it is never shortened for a release already out.

These projects are free and provided "AS IS" under the Apache License 2.0 (sections 7 and 8).
Support here means the channels above and the security fixes in this period, nothing more. No
response time, update, or fitness for any purpose is promised.
