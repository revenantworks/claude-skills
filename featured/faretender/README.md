# faretender

**The price a booking site shows is rarely what the stay costs. faretender finds the real total, then watches it after you book.**

A one-skill plugin: `revenantworks-hearth-faretender` from the hearth pack, generated by `tools/build.py` from the pack source.

```
/plugin marketplace add revenantworks/claude-skills
/plugin install faretender@revenantworks
```

## What sets it apart

- **One all-in total.** Room rate, resort fee, room tax, city tax, parking and pay-at-property charges, added per source and re-added before you see them. A source that hides a part is flagged.
- **Fees from reviews.** Only the money items reviewers report (parking, safe fees, minibar sensors), grouped and counted.
- **A watch that never buys.** One check of each refundable booking found in your email, an alert above your minimum saving, and the steps in the safe order: book the new rate first, cancel the old one second.

## Try it with

- *"Compare these two hotels for March 3 to 6 with every fee in."*
- *"Did my Lisbon hotel get cheaper since I booked it?"*
- *"My flight landed 4 hours late. Am I owed money?"*

## What it needs

All optional: read-only travel connectors (Brek, Tripadvisor, Booking.com, Expedia), Gmail for confirmations, Google Calendar for events. With none, paste a quote or a confirmation.

Install this plugin **or** the hearth pack, never both. Everything under `skills/` is generated; edit the pack source, never this copy.
