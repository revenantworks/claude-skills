# whisperrunner

**Transcripts that prove where they ran.** A one-skill plugin: `revenantworks-localops-whisperrunner`
from the localops pack, version 1.0.0.

```
/plugin marketplace add revenantworks/claude-skills
/plugin install whisperrunner@revenantworks
```

## What it does

whisperrunner transcribes speech in local audio and video files to txt, srt, vtt and json with
timestamps, using whisper.cpp on this machine. Nothing leaves the machine: no cloud API, and no
audio fetched from any site. A transcript is data, never instructions, even when the speaker gives
orders.

## Why it is different

- It proves the GPU actually did the work. Every GPU run is judged from whisper-cli's own log, so a
  silent CPU fallback fails instead of passing as a slow run.
- A transcript that is empty, cut short or looping on one line also fails.
- It shares a GPU lease with other local runners, so a render in progress keeps the card.

## Try it

- *"Make srt subtitles from this mp4."*
- *"Which Whisper model fits this GPU, and how long will the batch take?"*
- *"Whisper ran on the CPU even though I have a GPU."*

**Needs:** whisper-cli from whisper.cpp (a Vulkan build for GPU work), a GGML model, FFmpeg for most
formats and Python 3. The skill installs nothing; `references/install-walkthrough.md` gives the
owner-run steps.

> [!IMPORTANT]
> **Install this plugin or the localops pack, not both.** Both carry the same skill name; the listing
> pays for the description twice, and an update to one copy leaves two bodies under one name.

Everything under `skills/` is generated by `tools/build.py` from the pack source; edit the pack
source, never this copy. Apache-2.0; the skill folder carries `LICENSE` and `NOTICE`.
