# pixelsmith

**Pixel art that reads at every zoom.** A one-skill plugin: `revenantworks-gamedev-pixelsmith`
from the gamedev pack, version 1.0.0.

```
/plugin marketplace add revenantworks/claude-skills
/plugin install pixelsmith@revenantworks
```

## What it does

pixelsmith directs pixel art for a game whose one camera shows the world at several zoom levels:
people up close, groups at mid range, whole territories far out. Each asset is drawn once and must
still read at every level. pixelsmith writes the rules for each zoom band, runs a look test on one
scene, and writes briefs for an artist or an image generator. It does not draw.

## Why it is different

- **Every band, not one scale.** Sprite generators and pixel-art guides stop at one size.
  pixelsmith writes a value ladder, silhouette rules and icon rules per band, plus a "reads"
  checklist for each.
- **Contrast is a number.** Terrain against unit is measured as a value gap, with a fix ladder, so
  "the hut vanishes in the grass" becomes a figure and a cheapest fix.
- **A repeatable look test.** One scene, every band, a scorecard with a pass line. It also covers a
  pixelated 3D or 2.5D band with billboard sprites.
- **Works without an image tool.** It scores a picture when it can see one, and runs the full test
  from a described scene when it cannot.

## Try it

- *"This hut vanishes against the grass when zoomed out."*
- *"Run the look test on this scene."*
- *"Brief the pixel artist for the far-zoom unit icons."*

**Needs:** nothing to work. An image tool lets the look test score the picture. One optional
Python script for diffusion output uses only Python's built-in library.
