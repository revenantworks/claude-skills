# Security Policy: pacewright

## Supported versions

| Line | Security fixes until |
|---|---|
| 1.x | 2027-11-23 |
| older | none (end-of-life) |

Only the latest release in a supported line gets fixes. The dates match [`SUPPORT.md`](SUPPORT.md).

## How to report

Do not open a public issue. Use the repository's private form:
<https://github.com/revenantworks/claude-skills/security/advisories/new>.
This is the vulnerability-report channel for this plugin's listing in Anthropic's plugin
directory; reports from Anthropic and from anyone else go to the same place.

Include the plugin name, what you found, where it is (file and line), and steps to reproduce it.
Use placeholders instead of real secrets or other people's data.

## What to expect

We aim to reply within 7 days and to share a fix or a plan within 30 days. These are goals, not
guarantees. Every report is investigated with a reasonable standard of care. Disclosure is
coordinated, and reporters are credited unless they ask us not to be. The full policy is the
repository's [`SECURITY.md`](https://github.com/revenantworks/claude-skills/blob/main/SECURITY.md).
