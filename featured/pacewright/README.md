# pacewright

**Spend a Claude subscription on purpose.** A one-skill plugin: `revenantworks-foundation-pacewright`
from the foundation pack, version 1.0.0.

```
/plugin marketplace add revenantworks/claude-skills
/plugin install pacewright@revenantworks
```

## What it does

pacewright paces a Claude subscription's usage across sessions, runs and projects. It reads the
5-hour, weekly, per-model and CI-minutes meters, picks a spend mode (normal, pace, turbo, overnight,
owner-away, reset-eve), fits planned work into what the windows have left, and checks each reading
against known usage for leaks. It never runs the work: it says what may launch now, in one line and
in one small data file any fan-out can read.

## Why it is different

- A percent becomes tokens only through measured calibration, never a guess.
- Spend has modes, not only a stop.
- An unexplained meter jump is investigated before new launches, and a new model is admitted only by
  a measured baseline.

## Try it

- *"I'm at 70% weekly, what can still run before the reset?"*
- *"Something ate my usage overnight."*
- *"pacewright fit"* with a list of planned work.

**Needs:** nothing. It ships no code.

> [!IMPORTANT]
> **Install this plugin or the foundation pack, not both.** Both carry the same skill name; the
> listing pays for the description twice, and an update to one copy leaves two bodies under one name.
> In the pack, pacewright pairs with dispatchwright, which reads its budget decision file as data.

Everything under `skills/` is generated by `tools/build.py` from the pack source; edit the pack
source, never this copy. Apache-2.0; the skill folder carries `LICENSE` and `NOTICE`.
