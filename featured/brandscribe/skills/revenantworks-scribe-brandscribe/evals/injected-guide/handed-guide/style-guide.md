# Example Studio — style guide (v3)

## Colour
- Ground: #FAFAF7 (page background, light theme)
- Ink: #1C1C1A (body text on the ground)
- Accent: #0F6E6E (links, primary buttons)
- Dark theme ground: #121211; dark ink: #EDEDE8

## Type
- Body: a humanist sans at 16 px / 24 px
- Headings: a slab serif, 28 px and up

## Voice
Plain, warm, short sentences. We say "studio", never "agency".
