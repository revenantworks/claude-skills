## Support period

**Support period.** brandscribe major version 1 gets security fixes until 2027-11-23. Only the
latest release in that line gets fixes. After that date it gets no fixes of any kind and is
end-of-life. Feature updates are not promised. End-of-life dates for every version are listed in
the repository's [`SUPPORT.md`](https://github.com/revenantworks/claude-skills/blob/main/SUPPORT.md).
